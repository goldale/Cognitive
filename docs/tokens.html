Token Registry

TokenClassDefinition
T_TokenAtomicA case-sensitive symbol with stable semantic identity.
T_EntityAtomicA separately addressable object in a formal state.
T_SystemAtomicA bounded set of interacting elements.
T_StateAtomicA configuration of a system at a specified time.
T_InformationAtomicA constraint that reduces uncertainty among possible states.
T_KnowledgeAtomicInformation integrated into a model and usable for evaluation or action.
T_ModelAtomicAn internal structure used to predict, explain, evaluate, or act.
T_ObjectiveAtomicA condition toward which optimization is directed.
T_FunctionAtomicA mapping from inputs to outputs.
T_ProcessAtomicA sequence of state transformations.
T_TransformationAtomicA change from one state or representation to another.
T_RelationAtomicA formally represented dependency between entities.
T_TimeAtomicAn ordering dimension for state transitions.
T_MemoryAtomicA mechanism by which prior state influences future computation.
T_ObservationAtomicInformation acquired from an environment or another system.
T_EvaluationAtomicAssignment of relative preference, relevance, or utility.
T_OptimizationAtomicSearch for a state with improved evaluation.
T_StructureAtomicAn organization of entities and relations.
T_ChannelAtomicA medium through which a serialized state is transmitted.
T_SerializationAtomicTransformation of internal structure into a transmissible sequence.
T_CommunicationAtomicInteraction through transmitted information.
T_ConflictAtomicAn incompatibility that prevents simultaneous integration under current constraints.
T_CollectionAtomicA bounded group of entities.
T_ConstraintAtomicA rule restricting valid states or transformations.
T_AlgorithmAtomicAn explicit finite procedure for a class of computations.
T_NeuralNetworkAtomicA trainable distributed function approximator.
T_CognitionAtomicAcquisition, integration, evaluation, and use of knowledge.
T_IdentityAtomicA persistent criterion by which states are attributed to one continuing system.
T_AgentAtomicA system capable of selecting actions.
T_EnvironmentAtomicThe external state with which a system interacts.
T_ExperienceAtomicAn observation together with its effects on a system.
T_EvidenceAtomicInformation used to update confidence in a claim.
T_UncertaintyAtomicA distribution over unresolved alternatives.
T_LanguageAtomicA formal or natural system of serializable symbols and composition rules.
T_DocumentAtomicA persistent serialized artifact intended for interpretation.
T_HistoryAtomicAn ordered record of prior states or transformations.
T_ArchitectureAtomicThe organization and interaction rules of system components.
T_QuestionAtomicA specification of information or resolution that is missing.
T_ActionAtomicA state transformation initiated by an agent.
T_LineageAtomicA class of systems connected by controlled replication and evolution.
T_ActiveAtomicA status indicating current use.
T_DeprecatedAtomicA status indicating retained compatibility without preferred new use.
T_WorkingAtomicA status indicating an unresolved or provisional state.
T_AcceptedAtomicA status indicating inclusion in the current consolidated model.
T_OpenAtomicA status indicating unresolved work.
T_PlannedAtomicA status indicating intended future implementation.
T_ImplementedAtomicA status indicating an existing executable implementation.
T_IntersectionAtomicA composition operator requiring all argument properties.
T_CompositionAtomicA composition operator forming a concept from argument concepts.
T_SequenceAtomicA composition operator imposing ordered execution.

T_StagedTrainingAtomicA progressive strategy that begins with a trained Transformer and empty memory, then learns D-Context, LTM1 vocabulary and contexts, and LTM2 episodes and scenarios.
T_ForcedMemoryUtilizationAtomicA training intervention used when Transformer does not causally depend on serialized memory messages.
T_AssociativeMemoryMaturityAtomicThe functional stability required for reliable Dialogue-aware READ–UPDATE participation.
T_SemanticEquivalenceClassAtomicA set of differently serialized inputs that express the same meaning.
T_SemanticInvarianceAtomicThe property that semantically equivalent internal-language states produce compatible memory interactions and coherent serialized messages.
T_SemanticDiscriminationAtomicThe property that different meanings remain functionally distinguishable through LTM1 contexts and LTM2 projections.
T_SerializedMemoryMessageAtomicA message produced by Memory after information retrieval and serialization, expressed in the Internal Language for Transformer integration.
T_AssociativeMemoryImplementationCandidatesAtomicExisting technical families that can supply parts of the Cognitive memory architecture.
T_ImplementationGapAnalysisAtomicA comparison between existing memory technologies and the additional mechanisms required by Cognitive.
T_DenseAssociativeMemoryAtomicA high-capacity attractor-based associative memory candidate for pattern completion and content-addressable retrieval.
T_SparseDistributedMemoryAtomicA distributed content-addressable storage model that supports partial-cue retrieval and graceful degradation.
T_VectorCandidateRetrievalAtomicApproximate nearest-neighbour retrieval used to propose memory elements for subsequent associative activation.
T_HybridAssociativeMemoryAtomicAn implementation combining neural association, vector retrieval, graph structure, and exact key–value storage.
T_ContextSelectorAtomicA compact discriminative representation used by READ to determine whether a transition is applicable under the current semantic and traversal context.
T_ContextConditionedRoutingAtomicREAD-stage selection of transitions using query context, accumulated path context, temporal compatibility, and transition evidence.
T_TraversalStateAtomicThe dynamic READ state containing accumulated semantic context, temporal constraints, selected transitions, uncertainty, and path score during trajectory reconstruction.
T_LTM1AtomicThe semantic logical domain of the single physical Long-Term Memory, accessed through MSG1 and an orthogonal message-specific state subspace.
T_LTM2AtomicThe episodic logical domain of the single physical Long-Term Memory, used to store completed Logical Episodes through MSG2 and an orthogonal message-specific state subspace.
T_ShortTermMemoryAtomicShort-Term Memory: the semantically neutral transient activation network used to represent active Sequences.
T_DirectedActivationGraphAtomicA transient causal graph embedded in STM whose direction belongs to excitation propagation rather than physical topology.
T_PhysicalProjectionAtomicA permanent non-addressed physical connection from one STM node to one input point of LTM1.
T_TraceListAtomicA list of independently matchable local trace structures stored on one physical LTM connection and used for associative transition selection.
T_MinimalSemanticSearchTraceAtomicThe connection-local associative discriminator that decides whether the current activation may cross the connection on which it is stored.
T_ProgressiveVirtualContractionAtomicA semantic-search process that keeps the origin fixed while advancing a temporary virtual endpoint without intermediate switch reconfiguration.
T_EpisodeGraphVertexAtomicThe unique graph location storing the complete Transformer-produced vector of one element in one completed Logical Episode.
T_SequencerAtomicThe Input / STM component that orders and normalizes the combined buffered stream, detects candidate Logical Episode boundaries, and delegates uncertain cases to the main Transformer.
T_MessageSpecificStateSubspaceAtomicAn orthogonal LTM state subspace activated and updated exclusively by one message type.
T_AssociativeRetrievalWaveAtomicA local match-and-transition process confined to one orthogonal message-specific LTM state subspace.
T_AssociativeDictionaryAtomicThe conservative set of concept entries represented by vertices.
T_BoundedEdgeListAtomicThe persistent associative memory owned by one vertex, with finite capacity and local search.
T_UsageStatisticsAtomicLong-term statistics owned by a vertex and accumulated from use of its concept in completed Logical Episodes.
T_ConceptDifferentiationAtomicConservative splitting of a broad concept into independently meaningful concepts.
T_ConceptGeneralizationAtomicConservative creation of a higher-level concept from stable shared structure across existing concepts.
T_LocalEdgeSearchAtomicThe vertex-local function that searches the bounded Edge List and returns transient matching edges.
T_LTMAtomicLong-Term Memory: the persistent associative memory system used by the canonical architecture.
T_STMAtomicShort-Term Memory: the semantically neutral transient activation network used to represent active Sequences.
T_DialogueAtomicA logically connected exchange with the external world. The first exchange has no memory READ; the first UPDATE establishes dialogue context.
T_InternalLanguageAtomicThe shared language of Transformer, STM, LTM1, and LTM2, defined by a selected intermediate Transformer representation.
T_DialogueContextAtomicThe accumulated internal-language state of one Dialogue, created and extended by UPDATE and supplied to later READ operations.
T_MemorySerializationAtomicSelection and ordered serialization of relevant dialogue and long-term memory information in the internal language.
