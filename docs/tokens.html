T_StagedTrainingAtomicA progressive training strategy that first stabilizes the Transformer with a null Memory Vector and then integrates Associative Memory.
T_NullMemoryVectorAtomicThe fixed all-zero canonical Memory Vector used while training the Transformer before Associative Memory is enabled.
T_ForcedMemoryUtilizationAtomicA training intervention used when the Transformer does not causally depend on the Memory Vector.
T_AssociativeMemoryMaturityAtomicThe representational stability required before Associative Memory is integrated with the Transformer.
T_SemanticEquivalenceClassAtomicA set of differently serialized inputs that express the same meaning.
T_SemanticInvarianceAtomicThe property that semantically equivalent inputs produce nearby canonical Memory Vectors.
T_SemanticDiscriminationAtomicThe property that semantically different inputs remain separated in canonical Memory Vector space.
T_MultilingualConsistencyAtomicSemantic invariance across equivalent messages expressed in different languages.
T_IntraClassDistanceAtomicDistance between Memory Vectors generated by inputs in the same semantic equivalence class.
T_InterClassDistanceAtomicDistance between Memory Vectors generated by inputs with different meanings.
T_MemoryVectorAtomicThe canonical public interface produced by an explicit Associative Memory READ operation.
T_MemoryVectorNormalizationAtomicThe staged canonicalization of Memory Vector through length normalization, post-stabilization orthogonalization, and sparse basis rotation.
T_OrthogonalCoordinatesAtomicA transformed coordinate system with negligible off-diagonal covariance for representative Memory Vectors.
T_SparseBasisRotationAtomicA basis rotation intended to minimize the number of non-zero or significantly active coordinates for simple meanings.
T_SequentialMemoryVectorNormalizationAtomicA staged canonicalization process: length normalization first, statistical orthogonalization after semantic stabilization, and sparse basis rotation last.
T_LengthNormalizationStageAtomicThe first canonicalization stage, which normalizes every non-zero raw Memory Vector by Euclidean length while retaining activation magnitude separately.
T_StatisticalOrthogonalizationStageAtomicThe post-stabilization stage that estimates covariance and transforms Memory Vector coordinates toward negligible off-diagonal coupling.
T_SparseRotationStageAtomicThe final normalization stage that rotates an approximately orthogonal basis to reduce the number of materially active coordinates for simple meanings.

T_ImplementationGapAnalysisAtomicA comparison between existing memory technologies and the additional mechanisms required by Cognitive.

T_SparseDistributedMemoryAtomicA distributed content-addressable storage model that supports partial-cue retrieval and graceful degradation.
T_VectorCandidateRetrievalAtomicApproximate nearest-neighbour retrieval used to propose memory elements for subsequent associative activation.
T_HybridAssociativeMemoryAtomicAn implementation combining neural association, vector retrieval, graph structure, and exact key–value storage.
T_ContextSelectorAtomicA compact discriminative representation used by READ to determine whether a transition is applicable under the current semantic and traversal context.
T_ContextConditionedRoutingAtomicREAD-stage selection of transitions using query context, accumulated path context, temporal compatibility, and transition evidence.

T_DirectedActivationGraphAtomicA transient causal graph embedded in STM whose direction belongs to excitation propagation rather than physical topology.
T_PhysicalProjectionAtomicA permanent non-addressed physical connection from one STM node to one input point of Semantic LTM.
T_TraceListAtomicA list of independently matchable local trace structures stored on one physical LTM connection and used for associative transition selection.
T_MinimalSemanticSearchTraceAtomicThe connection-local associative discriminator that decides whether the current activation may cross the connection on which it is stored.
T_ProgressiveVirtualContractionAtomicA semantic-search process that keeps the origin fixed while advancing a temporary virtual endpoint without intermediate switch reconfiguration.
T_EpisodeGraphVertexAtomicThe unique graph location storing the complete Transformer-produced vector of one element in one completed Logical Episode.
T_EpisodeBoundaryTransformerAtomicA specialized Transformer that detects logical episode boundaries and delegates uncertain cases to the main Transformer.
T_MessageSpecificStateSubspaceAtomicAn orthogonal LTM state subspace activated and updated exclusively by one message type.
T_AssociativeRetrievalWaveAtomicA local match-and-transition process confined to one orthogonal message-specific LTM state subspace.
