Chapter 11

Associative Memory

Section 11.1

First exchange of a Dialogue

A Dialogue is a logically connected external exchange whose D-Context is created by the first UPDATE. The Transformer first converts the external input into a message in its internal language. Memory never receives raw external data.

  • Transformer processes the first external message without memory READ.
  • UPDATE transfers the resulting internal state into STM.
  • The first UPDATE creates D-Context in STM within Associative Memory. Subsequent UPDATE operations update this D-Context, and corresponding READ operations reuse it.
  • D-Context provides the context in which Associative Memory creates its messages for the Transformer, allowing the Transformer to follow the topic of the conversation with the external interlocutor without having to reread the entire conversation from the beginning with every new exchange.

Continuing Dialogue cycle

  • Transformer converts the next external message into an internal-language representation.
  • STM emits READ through MSG2 to LTM1.
  • LTM1 activation and LTM2 retrieval select relevant previous Dialogue content and long-term projections.
  • Memory serializes the selected information in the internal language.
  • Transformer continues processing with the Serialized Memory Message.
  • UPDATE stores the resulting new internal state and extends D-Context.

One language, two directions

Transformer-to-memory and memory-to-Transformer communication use the same internal language. READ differs from UPDATE by operation and cognitive role, not by semantic representation space. For the Transformer, this language is native and requires no additional translation or adaptation steps. Associative Memory, however, requires a complex initialization mechanism in which it learns a vocabulary of internal terms and their semantics. The detailed initialization algorithm is currently preserved in the research source files Dynamic_Associative_Memory_Transformer_EN.tex and Dynamic_Associative_Memory_Transformer_RU.tex, which retain research information and provide source material for articles published elsewhere. The relevant description will later be incorporated into the primary Cognitive documentation.

LTM1 / Vocabulary Structural Stability

Once the LTM1 vocabulary has been initialized, its learned internal terms, semantic mappings, atoms, contexts, and persistent associative structure remain structurally stable during waking operation. READ and UPDATE may modify activation and LTM2 content, but structural changes to conservative LTM1 occur only during Sleep or Offline Consolidation.
