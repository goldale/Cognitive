Chapter 11

Associative Memory

Section 11.2

Internal-Language Memory Interface

The selected doubled Transformer layer is connected to Associative Memory through two directional transfer windows. The Transformer-to-memory window copies activation values from the original half of the selected layer into the corresponding memory registers. The memory-to-Transformer window copies retrieved-state values from memory into the added, second half of the same selected layer. A window may be implemented in hardware or software; the architectural requirement is the direct transfer of these native internal values, not a particular copying mechanism.

The Transformer is trained to consume the vector placed in the added half of the selected layer and integrates it into its subsequent computation and the overall flow that generates the result. No conversion to text, tokens, symbolic commands, JSON, or an external embedding space occurs at this interface.

The vector may encode activation across a graph, spreading activation results, confidence, context, and other state. The public contract must remain stable even when the internal memory implementation changes.
