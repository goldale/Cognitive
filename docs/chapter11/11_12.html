Chapter 11

Associative Memory

Section 11.12

Sequential Multimodal Input Buffer

Input Buffer

A modality-neutral temporary stream of input activations before they enter active Transformer/STM processing. It is not semantic memory and performs no associative lookup.

No separate sequencing component

Input order is preserved by the producing stream and the receiving activation path. The architecture introduces

Boundary inference is cognitive processing

When an episode or segment boundary must be inferred rather than supplied by the source, that inference belongs to Transformer cognitive processing. It does not justify a separate architectural component.
