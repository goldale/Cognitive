Chapter 11

Associative Memory

Section 11.15

Vertex-Owned Associative Memory and Conservative Codebook Evolution

Epistemic status

Working architectural hypothesis defining conservative LTM1 evolution and Transformer-specific memory.

Transformer-defined vocabulary

The internal language is defined by the trained Transformer. LTM1 does not invent a separate native communication language.

Conservative LTM1

During waking operation LTM1 is structurally immutable. It performs associative activation and local READ/UPDATE interpretation using its existing atoms, contexts, and links.

Sleep-only structural change

New atoms, retired atoms, splits, merges, and permanent link changes are permitted only during sleep after analysis of accumulated LTM2 experience.

Early development resembles child learning: LTM1 first acquires a stable vocabulary and contexts in the Transformer internal language; LTM2 then increasingly accumulates compositions, episodes, and scenarios.

Memory serialization

Memory selects relevant prior Dialogue content and its projection onto LTM1 and LTM2, then serializes it in the internal language for Transformer.

Return path

Transformer places the new internal state into STM. STM-node activation emits MSG2 UPDATE; confirmed associative matches extend D-Context and LTM2.

No waking codebook drift

Because LTM1 changes only during sleep, Transformer and memory use a stable shared semantic interface throughout each waking period.
