Chapter 3

Internal Language

Section 3.2

Transformer Intermediate Representation

The Internal Language is observed through a selected intermediate Transformer layer, but it is not created by that layer alone. Its structure is determined jointly by the Transformer topology, learned connection parameters, training data, and training objectives. Consequently, two instances of the same network architecture trained on the same dataset may develop different Internal Languages, including when they are optimized for different objectives. These differences simply exist as a consequence of topology and learning; this architecture does not classify them as inherently beneficial or detrimental and does not infer semantic stability, compositionality, context sensitivity, or memory interoperability from their existence.

Implementation-dependent layer selection

Transformer specialists must select and justify the layer, layer combination, or learned projection that best exposes the Internal Language produced by the concrete topology and training regime. The optimal Transformer layer or layers for READ extraction, READ response reinjection, and UPDATE extraction remain implementation-dependent and are subjects of RS-0011.

Not an arbitrary fixed layer

No universal Transformer layer is prescribed as the memory interface. Layer placement is implementation-dependent and must be established experimentally for each Transformer topology and training regime.

The interface is Transformer-specific. Replacing Transformer may require migration, adaptation, or reconstruction of memory because another model may define a different internal semantic space.

Asymmetric Extraction and Reinjection

Asymmetric Transformer interface

The point that extracts a memory-facing Internal Language state and the point that receives the READ response may be distinct. External input is first transformed by earlier Transformer layers. The READ response is already expressed in the Internal Language and may therefore be reinjected deeper into the Transformer. The optimal layers for READ extraction, READ response reinjection, and UPDATE extraction are implementation-dependent and will be investigated in RS-0011.

external input -> early interpretation -> internal-language extraction point -> READ
serialized memory -> deeper reinjection point -> integration and reasoning

No repeated translation

A READ response expressed in the Internal Language need not be routed through the same early layers that process raw external form. Its reinjection layer is implementation-dependent and remains an RS-0011 research question.

Layer-placement research status

No numerical layer offset is fixed by the architecture. RS-0011 will investigate at which Transformer layer or layers READ extraction, READ response reinjection, and UPDATE extraction should occur.
