Chapter 3

Shared Internal Language

Section 3.2

Transformer Intermediate Representation

The internal language is obtained from a selected intermediate Transformer representation or from a stable projection of that representation. The architecture does not prescribe one universal layer number.

Implementation-dependent layer selection

Transformer specialists must select and justify the layer, layer combination, or learned projection that best preserves semantic stability, compositionality, context, and bidirectional usability by memory.

Required propertyReason
Semantic stabilityEquivalent meanings should produce sufficiently compatible memory interactions.
Context sensitivityThe same element in different contexts must remain distinguishable.
Bidirectional usabilityMemory output must be consumable by later Transformer processing.
Dimensional stabilityPersistent memory must not depend on incidental runtime tensor layout.
Task relevanceThe representation must retain distinctions needed by the trained Transformer and its objectives.

Not an arbitrary hidden state

A raw hidden state is not automatically a suitable architectural interface. The selected representation requires empirical validation and may need a stable normalization or projection.

The interface is Transformer-specific. Replacing Transformer may require migration, adaptation, or reconstruction of memory because another model may define a different internal semantic space.

Asymmetric Extraction and Reinjection

Asymmetric Transformer interface

The point that extracts a memory-facing internal-language state and the point that receives serialized memory are distinct. External input must first be translated by early Transformer layers. Memory output is already expressed in the shared internal language and is therefore reinjected deeper, into layers responsible for semantic integration, reasoning, planning, and response formation.

external input -> early interpretation -> internal-language extraction point -> READ
serialized memory -> deeper reinjection point -> integration and reasoning

No repeated translation

Serialized memory must not be routed through the same early layers that translate raw external form. Reprocessing internal-language memory as external input is redundant and may distort the preserved semantic state.

Working depth hypothesis

A working hypothesis is that the Memory Reinjection Point should be approximately 20–30% of Transformer depth later than the Internal-Language Extraction Point. The exact offset is implementation-dependent and must be established experimentally for each Transformer family.

Interface pointFunction
Internal-Language Extraction PointProduces the shared internal representation used to initiate READ and to form UPDATE content.
Memory Reinjection PointReceives serialized memory after early external-form interpretation and integrates it into later Transformer computation.
