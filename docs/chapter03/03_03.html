Chapter 3

Shared Internal Language

Section 3.3

One Language Across Cognitive Subsystems

The same internal language is used in both directions. Transformer sends READ and UPDATE content through STM; memory returns serialized relevant information to Transformer without semantic translation.

SubsystemRole in the shared language
TransformerCreates and interprets internal-language states.
STMOrders, transports, and maintains active Dialogue context without defining semantics.
LTM1Organizes stable internal-language atoms, contexts, and associative transitions.
LTM2Stores compositions, episodes, scenarios, and Dialogue history in the same language.

No raw external input to memory

Raw text, pixels, audio, video, packets, or other external observations never enter LTM1 or LTM2 as semantic input. Transformer interprets them first.

READ and UPDATE share one semantic space

READ and UPDATE differ by operation and cognitive role, not by representation language.

Language(READ input) = Language(UPDATE input) = Language(memory serialization)

RN-0002 — Translation as Cognitive State Reconstruction

Translation is treated as reconstruction of a compatible cognitive state rather than substitution of surface symbols. The shared internal language provides the system-level representation in which this compatibility can be tested.
