Chapter 3

Shared Internal Language

Section 3.4

Memory Serialization in the Internal Language

Memory does not generate an aggregated Memory Vector or invent a native response language. It selects relevant distributed state and serializes that information into an ordered internal-language sequence.

Memory Serialization

The ordered expression of selected relevant LTM1 and LTM2 information in the shared internal language.

  • Which atoms, contexts, episodes, compositions, or scenarios are relevant.
  • How repeated or competing information is reduced.
  • How context and relations are ordered.
  • How uncertainty, salience, and boundaries are represented.
  • When the serialized message is complete.
Relevant distributed memory state -> ordered internal-language sequence

Memory Vector terminology

Memory Vector may remain as a low-level implementation term for one vector element of a serialized memory message. It is not a separate language, a complete memory state, or an independently generated aggregate.
