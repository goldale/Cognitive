Chapter 3

Architecture Consequences and Design Principles

Section 3.1

Canonical Architecture Overview

The architecture follows directly from one decision: persistent Associative Memory operates in a Transformer-defined latent Internal Language instead of through an external symbolic retrieval interface.

Physical architecture first

The top-level architecture contains the Transformer Cognitive Core, the Internal Latent Interface, and Associative Memory. Cognitive functions are explained later as behavior of this chain.

Implementation-dependent boundary

The exact Transformer layer or layers used for UPDATE extraction, READ extraction, and READ reinjection remain under RS-0011. Draft 05 uses Layer N and dual-width organization as a marked research proposal so the central mechanism is visible.
