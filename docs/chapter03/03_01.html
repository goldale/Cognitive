Chapter 3

Shared Internal Language

Section 3.1

Internal Language as a System Foundation

The shared internal language is the central organizing concept of Cognitive. It is not invented by empty memory and is not an independent protocol layered above Transformer cognition. It is inherited from a selected intermediate representation of the trained Transformer.

Foundational axiom

Transformer, STM, LTM1, and LTM2 communicate through one shared internal language. No subsystem defines a second semantic language requiring translation.

The trained Transformer therefore establishes the semantic coordinate system before Associative Memory contains any experience. Memory begins empty and develops as a Transformer-specific model of the experienced world.

Architectural consequence

The former problem of generating a native LTM1 language disappears. The remaining problem is selection and serialization of relevant distributed memory state.
