Chapter 4

Internal Language

Section 4.3

One Language Across Cognitive Subsystems

Short-Term Memory (STM)

The short-term transport substrate inside Associative Memory that carries internal-language messages and supports the active D-Context.

READ

The non-mutating operation through which Associative Memory returns relevant serialized memory content to Transformer.

UPDATE

The operation through which Transformer sends a new Internal Language state to Associative Memory and may modify Memory State.

Dialogue Context (D-Context)

The evolving state of one Dialogue maintained only inside Associative Memory. READ uses it for selection; UPDATE creates or extends it.

Transformer formulates and sends READ requests and UPDATE messages through STM. Memory returns READ content as serialized messages in the Internal Language. READ and UPDATE therefore use the same internal language.

SubsystemRole in the shared language
TransformerGenerates Internal Language states; formulates and sends READ requests and UPDATE messages.
STMStores the current D-Context, carries READ and UPDATE exchange, updates D-Context, and changes Memory state.
LTM1Contains the current set of stable Internal Language Atoms together with their Atom S-Contexts (Semantic Contexts).
LTM2Stores compositions, episodes, scenarios, and Dialogue history in the Internal Language.

No raw external input to memory

Raw text, pixels, audio, video, packets, or other external observations never enter LTM1 or LTM2 as semantic input. Transformer interprets them first.

READ and UPDATE share one semantic space

READ and UPDATE differ by operation and cognitive role, not by representation language.

Language(READ input) = Language(UPDATE input) = Language(memory serialization)

RN-0002 — Translation as Cognitive State Reconstruction

Translation is treated as reconstruction of a compatible cognitive state rather than substitution of surface symbols. The internal language provides the system-level representation in which this compatibility can be tested.
