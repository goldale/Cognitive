Chapter 4

Internal Language

Section 4.4

Memory Serialization in the Internal Language

Memory serialization occurs only in the context of a Dialogue. It is not a general export of STM, LTM1, or LTM2 state and does not reproduce the complete state of memory.

Memory Serialization

The expression, as an ordered message in the Internal Language, of the information subset selected for the current Dialogue.

Dialogue-centered serialization

D-Context defines the serialization subset. Memory performs the serialization.

The current D-Context is stored in STM. After early Transformer layers interpret an external request, Transformer formulates and sends a READ request. Memory performs information retrieval and serialization using the current D-Context from STM.

READ content returns as a serialized message in the Internal Language. It is reinjected into deeper Transformer layers, where it is integrated with the interpreted external request for reasoning and response formation.

  • the current subject and active goals of the Dialogue;
  • entities, relations, and decisions already established in the Dialogue;
  • unresolved references, questions, and hypotheses;
  • relevant stable Internal Language Atoms and their Atom S-Contexts in LTM1;
  • relevant compositions, episodes, scenarios, and Dialogue history in LTM2;
  • temporal, causal, confidence, and relevance constraints required for continuation.
D-Context from STM -> serialization subset -> information retrieval -> serialized Internal Language message

Relation to communication between cognitive systems

Earlier work on communication established that a serialized signal acquires meaning only relative to a compatible semantic system and shared context. Memory serialization applies the same principle internally: memory and Transformer communicate through the Internal Language, while D-Context supplies the context that determines what information must be expressed.

Operational distinction

Transformer formulates and sends READ and UPDATE messages. Memory retrieves and serializes information for READ. STM stores and updates D-Context and applies UPDATE to change Memory state.
