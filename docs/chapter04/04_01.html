Chapter 4

Internal Language

Section 4.1

Internal Language as a System Foundation

The internal language is the central organizing concept of Cognitive. It is not invented by empty memory and is not an independent protocol layered above Transformer cognition. It is inherited from a selected intermediate representation of the trained Transformer.

Foundational axiom

Transformer, STM, LTM1, and LTM2 communicate through one internal language. No subsystem defines a second semantic language requiring translation.

The trained Transformer therefore establishes the semantic coordinate system before Associative Memory contains any experience. Memory begins empty and develops as a Transformer-specific model of the experienced world.

Short-Term Memory (STM)

The short-term transport substrate inside Associative Memory that orders internal-language messages and supports the active D-Context.

Long-Term Memory 1 (LTM1)

The associative layer containing Internal Language Atoms and their Atom Semantic Contexts.

Atom Semantic Context (Atom S-Context)

The semantic context associated with an Internal Language Atom and used to constrain associative interpretation and retrieval.

Long-Term Memory 2 (LTM2)

The long-term layer that stores compositions, episodes, scenarios, and Dialogue history expressed in the Internal Language.

Dialogue Context (D-Context)

The evolving state of one Dialogue maintained only inside Associative Memory and used by READ to select relevant memory content.

READ and UPDATE

READ returns serialized memory content to Transformer; UPDATE sends a new Transformer-produced state into Associative Memory. Both use the Internal Language.
