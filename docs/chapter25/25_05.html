Section 25.5

Appendix H — Margin Notes

This registry points to canonical Margin Notes. Margin Notes preserve useful alternatives and side observations without making them part of the canonical architecture.

  • MN-0001 — Alternative parallel input processing
  • MN-0002 — Compressed or superposed Trace storage

Normative boundary

A Margin Note is documentation, not an architectural invariant. Adoption requires a separate release-level architectural decision and corresponding canonical changes.
