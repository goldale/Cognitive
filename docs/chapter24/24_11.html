Chapter 24

Open Research Questions

Section 24.11

Context-Conditioned Routing Across Overlapping Trajectories

Status

Working implementation hypothesis for conventional hardware. The graph terminology describes one possible READ-stage realization and does not redefine Associative Memory as a graph, Knowledge Graph, GraphRAG system, or vector database.

Shared semantic states and overlapping trajectories

A semantic state S may participate in many episodic, temporal, or causal trajectories. The state itself does not identify one unique graph or episode. Distinct trajectories are recovered through context-conditioned transition selection rather than by assigning every occurrence of S to a separate physical node.

Trajectory A: A0 → A1 → S_mid → A3    Trajectory B: B0 → B1 → S_mid → B3    Trajectory C: C0 → C1 → S_mid → C3

During READ, candidate backward or forward transitions from S_mid are scored against the current query context and the context accumulated during traversal. The selected transition should maximize compatibility with the active trajectory rather than merely have the greatest global frequency.

score(e_k) = α·sim(Q_context, C_k) + β·W_k + γ·T_k + δ·P_k
  • Q_context is the current semantic query and accumulated traversal context.
  • C_k is the Context Selector associated with candidate transition e_k.
  • W_k is learned or observed transition strength.
  • T_k is temporal compatibility.
  • P_k is compatibility with the already reconstructed partial path.
  • α, β, γ, and δ are implementation parameters of READ.

Path continuity instead of isolated argmax

READ should update its traversal state after every selected transition. This reduces the risk of entering one trajectory at S_mid and then switching into another trajectory at a later shared state. The traversal state may include the semantic query, accumulated context, temporal constraints, selected transitions, uncertainty, and current path score.

S_mid → score candidate edges → select compatible transition → update traversal context → repeat → detect context boundary ΔC

A large context discontinuity may indicate that the traversal has reached an episode boundary or entered an incompatible branch. READ may stop, backtrack, retain multiple hypotheses, or begin a separate context segment. Boundary decisions should preferably use context windows and path-level evidence rather than a single adjacent-state comparison.

Canonical compact edge payload

A practical baseline edge stores only the destination, a reference to a Context Selector, a quantized transition strength, and relation or control flags. A typical packed representation is 16 bytes, subject to implementation-specific alignment.

GraphEdge { uint64 target_node_id; uint32 context_selector_id; uint16 transition_strength_q; uint16 flags; }

Context Selector

A Context Selector is a compact discriminative representation used to determine whether a transition is applicable under the current semantic state. It is not required to be a full copy of an episode context or a full dense embedding.

  • A quantized context prototype.
  • A binary semantic code.
  • A cluster or prototype identifier.
  • A residual relative to a shared context.
  • A subset of discriminative coordinates.
  • A learned routing key or another implementation-specific selector.

Context Selectors should normally be pooled and deduplicated. Many transitions can reference one selector through context_selector_id, while the encoded selector data and quantization metadata remain in separate dense storage. This avoids duplicating a full semantic vector on every edge.

Performance interpretation

Compact edges do not make the complete graph fit into ordinary CPU cache. They reduce memory bandwidth, cache-line traffic, and pointer overhead, allowing active adjacency lists and frequently used Context Selectors to use CPU caches more effectively. End-to-end transition latency depends on cache locality, candidate count, selector encoding, and the scoring implementation; it must not be inferred from the latency of one SIMD or POPCNT instruction.

  • Context-conditioned transition routing is an implementation mechanism of READ.
  • Vector indexes, graph stores, and Context Selector tables may support READ but are not Associative Memory itself.
  • UPDATE may create, strengthen, weaken, merge, or reassign transitions and selectors, but canonical READ remains non-mutating.
  • Associative Memory remains the continuously evolving semantic substrate of the Cognitive architecture.

Working hypothesis

When one semantic state participates in many overlapping trajectories, the appropriate trajectory can be reconstructed through path-consistent, context-conditioned edge selection. Compact edge payloads reference pooled Context Selectors, while accumulated traversal context and ΔC boundary detection prevent uncontrolled mixing of episodes.
