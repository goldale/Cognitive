Chapter 10

Associative Memory

Section 10.13

Logical Episode Consolidation Boundary

Physical order is not a logical episode

The Input Buffer always produces one branch-free linear observation stream. This physical order preserves the sequence in which Cognitive receives events, but it does not by itself define where a semantically complete episode begins or ends.

E₁ → E₂ → E₃ → E₄ → E₅ → …

Graphs emerge after semantic interpretation

The external world may contain arbitrary graph structures, concurrent processes, and interacting causes. Input Buffer and STM do not store those graphs as explicit objects. Relational, causal, and graph structure emerges later through semantic interpretation.

Logical episode

A Logical Episode is a semantically coherent and sufficiently complete sequence whose logical start and logical end are inferred after semantic interpretation. Its boundaries are interpretations of the stream, not physical markers stored in Input Buffer or STM.

Canonical consolidation unit

The unit transferred into the second Long-Term Memory is not an individual event, not an STM node, and not an arbitrary temporal window. It is a logically bounded sequence inferred from semantic interpretation.

  • Input Buffer remains sequential, branch-free, fixed-size, circular, and semantically neutral.
  • STM remains semantically neutral and stores no objects, attributes, addresses, or explicit episode markers.
  • The Transformer may infer boundaries only from semantic evidence available downstream of Semantic LTM.
  • The second Long-Term Memory remains deferred until boundary inference and transfer semantics are specified and validated.
