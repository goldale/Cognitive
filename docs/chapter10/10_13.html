Chapter 10

Associative Memory

Section 10.13

Logical Episode Consolidation Boundary

Physical order is not a Logical Episode

The Input Buffer produces one branch-free linear observation stream. This physical order preserves the sequence in which Cognitive receives events, but it does not define where a semantically coherent Logical Episode begins or ends.

E₁ → E₂ → E₃ → E₄ → E₅ → …

Logical Episode boundaries

The beginning and end of a Logical Episode are inferred from the combined semantic context of the buffered stream. The logical beginning need not coincide with the physical beginning of the Input Buffer.

Hierarchical boundary detection

A specialized Episode Boundary Transformer normally analyzes the buffered stream and returns candidate start and end boundaries together with confidence. If it cannot determine the boundaries with sufficient confidence, the same task is delegated to the main Transformer, which makes the final boundary decision.

Boundary detection and final processing are distinct

Repeated boundary analysis and final processing of a completed Sequence are separate Transformer operations. After both boundaries are known, the main Transformer processes the complete Sequence and produces one contextual data vector for every participating element.

Canonical consolidation unit

The canonical unit integrated into LTM through MSG2 is the completed Sequence selected by the inferred Logical Episode boundaries, together with the main Transformer output that defines per-element contextual data and causal graph topology.

Sequence

A completed Sequence determines the set of vertices belonging to one Logical Episode and preserves their original temporal order in STM. It does not determine the topology of the episode graph.

Temporal-to-causal transformation

The main Transformer determines directed causal relations between the corresponding vertices. The resulting episode graph may be branched, convergent, divergent, or disconnected and is not required to preserve the linear topology of the Sequence.

STM Sequence: A → B → D → E    ⇒    LTM episode graph: A → B, A → D, D → E

Sequence lifetime

The Sequence remains active in STM until the completed Logical Episode has been successfully integrated into LTM.

  • Input Buffer remains sequential, branch-free, fixed-size, circular, and semantically neutral.
  • Logical Episode boundaries are independent of physical Input Buffer boundaries.
  • A Sequence represents temporal input order; an episode graph represents causality.
  • No cognitive addresses or global episode identifiers are introduced.
