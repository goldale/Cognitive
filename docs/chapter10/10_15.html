Chapter 10

Associative Memory

Section 10.15

Vertex-Owned Associative Memory and Conservative Dictionary Evolution

Epistemic status

Working architectural hypothesis. It defines an implementable communication contract without claiming that the final biological realization is already known.

Native communication language

The native language between memory and Transformer is formed from associative atoms already present in LTM1. Transformer does not invent an independent semantic vocabulary.

Export mechanism

A deterministic external controller selectively excites or admits selected LTM1 nodes to repeated Memory Vector readout. Each Memory Vector element aggregates its assigned LTM1 contributors by MAX or SUM. Repeated measurements expose the required associative atoms as a stream consumable by Transformer.

MAX path

With MAX, repeated selective readout can expose the strongest eligible contributor and then the next eligible contributor. This creates a ranked native-language stream without requiring global LTM1 serialization.

SUM path

With SUM, repeated independently controlled projections create a system of linear measurements. If the projection system has sufficient rank, the selected contributors can be recovered by an external decoder. The decoder, not Transformer, performs the inversion.

Purpose of reconstruction

Recovering internal LTM1 node states is a means for constructing an efficient native communication language between LTM1, Transformer, and LTM2. It is not itself the persistent object stored in LTM2 and is not a requirement to serialize the complete state of LTM1.

Transformer composition

Transformer receives exported LTM1 atoms and combines them into contextual STM chains. Most semantic relations are themselves LTM1 atoms; only a very small structural-link alphabet is expected.

Contextual four-tuple

The working local composition is object, context, previous, next. Context is normally one or two existing LTM1 links. Previous and next are represented by the STM chain topology rather than duplicated as semantic fields.

Return path

Transformer places the completed construction directly into STM. STM-node activation emits MSG2(amplitude, sequence_number, operation). For UPDATE, the operation is UPDATE; the Sequencer is unnecessary because chain boundaries and order are already complete.

Match-gated LTM2 write

UPDATE excitation propagates only through LTM1. A receiving node becomes a candidate, and only a confirmed associative match may participate in the LTM2 composition write.
