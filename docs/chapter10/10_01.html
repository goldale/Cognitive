Chapter 10

Associative Memory

Section 10.1

Subsystem Separation

The near-term architecture separates a Transformer from Associative Memory. The Transformer performs language processing, general inference, planning, and response generation. Associative Memory stores accumulated experience, supports associative retrieval, and evolves independently. The generated answer must return to Associative Memory as an internal observation, creating a back link that keeps the cognitive cycle continuous rather than terminating at output generation. This feedback path modifies Associative Memory only; it does not perform a READ operation and therefore does not generate a new Memory Vector.

The back link is a key architectural requirement. An answer is not only an external response; it is also information produced by the system itself. Associative Memory receives that result as an internal observation and changes its internal state, including short-term activation and association context. The feedback path does not invoke projection, does not call the Transformer interface, and does not generate a new Memory Vector. A Memory Vector is produced exclusively by a subsequent explicit READ operation. Persistent learning remains a separate UPDATE path, and long-term knowledge may remain unchanged.

Architectural invariant: Memory Vectors are generated only by explicit READ operations. Feedback, UPDATE, learning, and Sleep may change Associative Memory, but none of these operations generates a Memory Vector by itself.

This is an engineering decomposition, not a claim that the mature architecture must remain permanently modular.
