Chapter 10

Memory Architecture

Section 10.1

The Biological Memory Hypothesis

Biological memory does not behave as a precise archive. Recall is selective, reconstructive, context-dependent, and vulnerable to systematic distortion. Cognitive therefore treats memory as an active model supporting present processing rather than as a passive record store.

Shared-language invariant

Memory output is not translated into a separate representation. It is serialized in the same Transformer-derived internal language used for READ and UPDATE.

Functional lossiness

Memory loss and reconstruction are partly selected because they improve integration and future action, not only because biological storage is limited.

Confidence: 0.78

The relevant objective is not exhaustive historical fidelity. It is useful continuity, prediction, and action under resource constraints.
