Chapter 10

Associative Memory

Section 10.1

Semantic Feedback Learning and Subsystem Separation

READ and UPDATE are phases of one Dialogue-aware cognitive cycle. Transformer first converts external input into the internal language. Memory never receives raw external data.

Dialogue

A logically connected external exchange whose context is established by UPDATE and reused by later READ operations.

First exchange of a Dialogue

  • Transformer processes the opening external message without memory READ.
  • Transformer produces a response or intermediate result.
  • UPDATE transfers the resulting internal state through STM.
  • Memory creates the initial D-Context and may store the first Dialogue episode in LTM2.

Continuing Dialogue cycle

  • Transformer converts the next external message into an internal-language representation.
  • STM emits READ through MSG2 to LTM1.
  • LTM1 activation and LTM2 retrieval select relevant previous Dialogue content and long-term projections.
  • Memory serializes the selected information in the internal language.
  • Transformer continues processing with the Serialized Memory Message.
  • UPDATE stores the resulting new internal state and extends D-Context.

One language, two directions

Transformer-to-memory and memory-to-Transformer communication use the same internal language. READ differs from UPDATE by operation and cognitive role, not by semantic representation space.

LTM1 structural stability

During waking operation READ and UPDATE may modify activation and LTM2 content, but structural changes to conservative LTM1 occur only during Sleep or Offline Consolidation.
