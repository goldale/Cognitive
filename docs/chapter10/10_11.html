Chapter 10

Associative Memory

Section 10.11

Semantically Neutral STM and Single Physical LTM

Epistemic status

Working Stage-1 architectural hypothesis. It fixes the present discussion state without claiming that the eventual biological or hardware implementation is already known. Later evidence may revise the hypothesis only through an explicit release-level architectural change.

Single physical LTM with two logical domains

The architecture contains one physical Long-Term Memory vertex and connection array. LTM-1 and LTM-2 are not separate physical memories. They are orthogonal logical domains implemented through different message types and message-specific state subspaces within the same physical LTM.

LTM-1

LTM-1 is the semantic logical domain of the single physical LTM. It contains stable Items of the world, basic properties, and a small bounded set of fundamental relations. Examples include chair–sit and bed–lie. In the initial architecture it is treated as effectively immutable, analogous to the initially cloned Transformer.

LTM-2

LTM-2 is the episodic logical domain of the same physical LTM. It stores completed Logical Episodes through MSG2 while remaining physically co-located with LTM-1 and isolated from it by an orthogonal message-specific state subspace.

  • An Item may later acquire a formally defined attribute set.
  • An Item may have more than one basic relation, with an initial working limit of no more than eight.
  • LTM-1 does not initially store the personal event sequences generated during operation.
  • LTM-1 is not a Vector Database, Knowledge Graph, or GraphRAG system; such mechanisms may support READ only.

Semantically neutral STM

STM contains no objects, labels, addresses, or intrinsic Item attributes. Its nodes are semantically neutral. Meaning arises only through the physical interaction of STM activity with LTM-1.

Physical topology of STM

STM is a fixed, fully connected, non-directed physical network. The physical connectivity is not created, deleted, or oriented for each sequence. The state of excitation changes rapidly; the underlying complete connectivity does not.

Sequence

A Sequence is a directed linear activation chain formed within the fully connected STM from the Input Buffer segment identified as one Logical Episode. The Sequencer assigns every active node a position number preserving the original input order.

Identified Input Buffer segment → directed linear STM Sequence
  • A Sequence is not an address chain or a permanently created set of physical links.
  • A Sequence is linear and preserves the observed temporal order of the selected Input Buffer segment.
  • Its direction represents input order, not causal structure.
  • Different Sequences may reuse and overlap the same semantically neutral STM nodes.
  • The Sequence remains active in STM until the completed Logical Episode has been successfully committed to LTM-2. After a successful commit, the beginning of the circular input buffer advances to the next Sequence, making the committed Sequence no longer part of STM.

STM–LTM-1 projection

Every STM node has one permanent physical projection to an input point of LTM-1. This projection is a physical connection, not an address, pointer, identifier lookup, or table-based binding.

STM node excitation → fixed physical projection → LTM-1 input excitation → massively parallel propagation and semantic stabilization

During one excitation, each active STM node is associated with semantic content only through the response that its fixed LTM projection participates in producing. The STM node itself does not become a chair, person, action, or other Item and retains no permanent semantic attribute after the excitation ends.

Parallel interpretation

A request excites a distributed linear STM Sequence. Every active Sequence node emits msg2(amplitude, sequence_number) through its permanent projection to the corresponding LTM input. The complete set of messages constitutes the READ stimulus.

Transformer boundary

The Transformer receives the fixed-dimensional Memory Vector generated from the distributed LTM response. Memory Vector coordinates are intentionally opaque and have no individually prescribed semantics; the Transformer is trained to use the joint pattern.

READ interpretation

READ is not address lookup or retrieval of a selected episode. Every node of the latest STM Sequence emits msg2(amplitude, sequence_number). MSG2 propagates exclusively through the persistent associative graph stored in LTM-1, and the resulting distributed response is reduced to the Memory Vector. READ remains non-mutating.

Single physical LTM

The architecture contains one physical LTM node and connection array. Semantic element processing and completed-episode processing use different message types and orthogonal message-specific state subspaces within that same LTM.

  • What node and connection variables implement the transient linear Sequence without changing physical STM topology?
  • How does the Sequencer estimate Logical Episode boundary confidence?
  • How are concurrent associative waves scheduled and measured in hardware?

Canonical LTM-2 READ algorithm

The latest event is represented by the linear STM Sequence produced by the Sequencer. The Sequencer numbers its nodes. Every active node emits msg2(amplitude, sequence_number) through its permanent STM-to-LTM projection. These messages excite the corresponding LTM inputs and propagate exclusively through the persistent associative graph stored in LTM-1. The distributed MSG2 response is then reduced to the fixed-dimensional Memory Vector.

Sequencer chain -> msg2(amplitude, sequence_number) -> propagation through persistent LTM-1 graph -> MAX or SUM readout -> Memory Vector

No independent LTM-2 propagation graph

LTM-2 does not have its own propagation logic or connectivity. It uses the existing associative structure of LTM-1 as its computational substrate while MSG2 state remains isolated in an orthogonal message-specific state subspace.

Persistent-graph invariant

The READ operation never creates temporary associative connections. Every msg2 propagates exclusively through the persistent associative graph stored in LTM-1. Consequently, the generated Memory Vector is a direct consequence of the accumulated associative structure of long-term memory rather than of the current STM event alone.

MSG2 payload

msg2(amplitude, sequence_number). Amplitude carries the STM activation strength. sequence_number carries the node position assigned by the Sequencer. The target concept identity is supplied by the permanent physical projection rather than encoded as an address in MSG2.

  • Set operation mode to READ.
  • Reset the fixed Memory Vector output cells.
  • Number all nodes of the latest linear STM Sequence.
  • Every active Sequence node emits msg2(amplitude, sequence_number).
  • Inject each message through the permanent projection to its corresponding LTM input.
  • Propagate every msg2 exclusively through the persistent LTM-1 associative graph.
  • Reduce the distributed response into Memory Vector cells using MAX or SUM.
  • Return the Memory Vector and clear transient MSG2 excitation.

Information-preserving readout selection

The initial implementation supports both MAX and SUM readout operators without assuming either is optimal. Under deterministic READ, both are evaluated on identical representative LTM states and Event Queries, and the operator producing the higher non-degenerate Memory Vector entropy is preferred. If READ becomes stochastic, mutual information must be used to distinguish memory-dependent information from internally generated noise.
