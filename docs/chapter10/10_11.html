Chapter 10

Associative Memory

Section 10.11

Semantically Neutral STM and Single Physical LTM

Epistemic status

Working Stage-1 architectural hypothesis. Later evidence may revise it only through an explicit release-level architectural change.

Single physical LTM with two logical domains

LTM1 and LTM2 may share one physical vertex and connection substrate while remaining distinct logical domains with different update rules.

LTM1

The conservative semantic-associative domain containing stable atoms, contexts, and persistent links in the internal language.

LTM2

The episodic and compositional domain storing Dialogue history, completed episodes, scenarios, and state transitions.

Semantically neutral STM

STM orders and transports internal-language states and maintains active D-Context. It does not define a second semantic vocabulary.

Sequence

An ordered activation chain in STM preserving the internal-language order of the current processing step or completed episode.

Transformer boundary

Raw external input is interpreted by Transformer before memory access. Memory receives and returns only internal-language representations.

Dialogue-aware READ

The first exchange of a new Dialogue has no READ. In later exchanges, STM emits MSG2 READ from the current internal-language quasi-query; LTM1 activation and linked LTM2 content are selected and serialized into a bounded memory message.

D-Context + Current Internal State -> MSG2 READ -> LTM1 Activation -> LTM2 Projection -> Serialized Memory Message

Transformer internal-language UPDATE

During processing, Transformer produces a new internal state. STM emits MSG2 UPDATE; receiving LTM1 nodes interpret UPDATE locally, and confirmed matches may extend D-Context and LTM2.

MSG2 payload

MSG2(amplitude, sequence_number, operation). operation is interpreted locally by the receiving LTM1 node and initially supports READ and UPDATE.

Persistent-graph invariant

READ and UPDATE propagate only through the persistent LTM1 associative graph. Waking operation does not structurally modify LTM1.

Match-gated LTM2 write

UPDATE requests associative matching; it does not directly authorize an LTM2 write. Only confirmed matches participate in the stored composition.
