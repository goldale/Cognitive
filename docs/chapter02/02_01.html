Chapter 2

Architecture Overview and Design Principles

Section 2.1

Canonical Architecture Overview

Cognitive uses one shared internal language across Transformer, STM, LTM1, and LTM2. The language is defined by a selected intermediate representation of the trained Transformer; memory begins empty and develops as a Transformer-specific long-term model of experienced reality.

Shared internal language

Raw external data never enters Associative Memory. External input is first interpreted by Transformer. Both READ and UPDATE use the same internal-language representation.

Dialogue

A logically connected exchange of messages with the external world. The first exchange is processed without memory READ. Its first UPDATE creates Dialogue Context; later READ operations may then supply previous dialogue content and its projection onto long-term memory.

Dialogue-aware READ and UPDATE

Dialogue phaseMemory participationResult
First external exchangeNo READTransformer processes the opening message; UPDATE creates Dialogue Context.
Continuing exchangeREAD before continued processingMemory returns previous Dialogue content plus its relevant projection onto LTM1 and LTM2.
After Transformer processingUPDATEMemory stores the new internal state and extends Dialogue Context.

Relevant memory serialization

Memory does not generate a separate Memory Vector language. It selects relevant distributed state and serializes it in the shared internal language.

LTM1 remains a conservative associative graph and changes structurally only during Sleep. LTM2 accumulates dialogue history, compositions, episodes, and scenarios. STM carries ordered internal-language messages and maintains the active Dialogue.

Asymmetric Transformer entry points

External messages enter through early Transformer interpretation. Memory-facing state is extracted only after internal-language formation. Serialized memory returns through a deeper Memory Reinjection Point because it is already expressed in the shared internal language and does not require another translation pass.

Depth hypothesis

The reinjection point is provisionally expected to lie approximately 20–30% of Transformer depth after the extraction point. This value is an experimental starting range, not a universal constant.
