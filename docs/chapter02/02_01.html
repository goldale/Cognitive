Chapter 2

Architecture Overview and Design Principles

Section 2.1

Canonical Architecture Overview

Cognitive is organized around a Transformer-defined Internal Language. External information is interpreted by Transformer before any memory operation, and all communication with Memory uses messages expressed in that Internal Language.

Internal Language as the system interface

Transformer determines and uses the Internal Language. Every cognitive subsystem communicates through that language rather than through a subsystem-specific representation.

Dialogue

A logically connected exchange of messages with the external world. Dialogue provides the continuity within which Transformer requests memory retrieval and sends memory updates.

Associative Memory

The memory subsystem that maintains experience-specific state and interacts with Transformer exclusively through UPDATE input and READ output expressed in the Internal Language.

UPDATE

The operation by which Transformer sends a new Internal Language state to Associative Memory. UPDATE may create or modify Memory State and the active Dialogue Context.

READ

The operation by which Associative Memory returns relevant serialized memory content to Transformer without modifying persistent Memory State.

Dialogue Context (D-Context)

The evolving state of one Dialogue maintained only inside Associative Memory. The first UPDATE creates the D-Context, later UPDATE operations extend it, and READ uses it to select relevant memory content.

Asymmetric Transformer entry points

External messages enter through earlier Transformer processing. READ extraction, READ response reinjection, and UPDATE extraction may occur at distinct layers. Their optimal placement is implementation-dependent and is the subject of RS-0011.

RS-0011 layer-placement question

The architecture does not prescribe a numerical depth offset. RS-0011 will investigate at which Transformer layer or layers READ extraction, READ response reinjection, and UPDATE extraction should occur.
