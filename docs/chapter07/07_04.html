Chapter 7

Integrated Evaluation and Functional Self

Section 7.4

Self as a System Regime

T_FunctionalSelf may not correspond to one module. It may be a stable attractor or invariant pattern of the entire cognitive system: the recurring organization through which memory, evaluation, goals, action, and continuity are jointly interpreted.

The integrated evaluator is a likely prerequisite because it supplies the common space in which otherwise unrelated consequences become comparable.

The Self then emerges when the evaluator, memory, causal model, and planner repeatedly close a loop around one persistent identity.

Self Model -> Action -> Environment -> Observation -> Evaluation -> Memory -> Self Model
