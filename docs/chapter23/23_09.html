Chapter 23

Open Research Questions

Section 23.9

Working Hypothesis for Offline Replay

Status

Working hypothesis preserved for research. The node-and-edge language below is explanatory and must not be interpreted as a claim that biological memory is literally a graph or that each event owns a dedicated cell array.

Event states and chronological transitions

A concrete event is represented as a recoverable distributed Event State. Chronology is represented functionally by reproducible, context-constrained transitions between Event States. A logical sequence E1 → E2 → E3 is therefore a projection of distributed memory dynamics rather than necessarily a set of physical graph nodes and pointers.

Event State E(t) ↓ strongest compatible learned transition ↓ Event State E(t+1) ↓ repeat

During sleep or another offline-compatible state, internal associative activation may reinstate an Event State. The memory dynamics then select a strong transition compatible with the already active episodic context, reinstate the next Event State, and continue the trajectory.

Statistical weight is not sufficient

An absolute maximum-weight rule would repeatedly select statistically typical continuations and could mix episodes. Transition selection must therefore combine learned strength with compatibility to the active trajectory, temporary suppression of recently replayed material, and possibly uncertainty or consolidation need.

Working replay hypothesis

Episodic chronology may be encoded as reproducible, context-constrained transitions between distributed event states. During offline processing, internal associative activation may reinstate an event state and initiate a trajectory through strong compatible transitions.

Even if later rejected, this hypothesis provides a concrete direction for studying both ordinary recollection and sleep replay. Explaining how an internally selected trajectory is replayed in the correct order may constrain the architecture of episodic storage more strongly than starting from static associative retrieval alone.
