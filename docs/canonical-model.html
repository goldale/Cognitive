Canonical Terminology

Semantic Teacher

The Transformer role that produces semantic representations suitable for Associative Memory learning.

Semantic Feedback Learning

Learning in which Transformer-produced semantic representations update Associative Memory.

Semantic Feedback Learning Pipeline

The first-class architectural process coordinating the closed self-learning loop.

Semantic Representation

The canonical semantic object accepted by UPDATE.

Memory State

The dynamic internal state of Associative Memory, including persistent and short-lived organization.

Memory Vector

The fixed-dimensional, opaque output produced by READ from the distributed MSG2 response of the current long-term-memory state to the latest Sequencer chain. Individual coordinates have no predefined semantics.

READ

The non-mutating operation in which every node of the latest STM Sequencer chain emits msg2(amplitude, sequence_number), MSG2 propagates exclusively through the persistent LTM-1 associative graph, and a readout operator produces the Memory Vector.

UPDATE

The Associative Memory operation that incorporates a Semantic Representation into Memory State and returns no Memory Vector.

Semantic Learner

The Associative Memory role that incorporates Transformer-produced Semantic Representations into Memory State through UPDATE.

Contextual Retriever

The Associative Memory role that produces a Memory Vector through explicit READ without modifying Memory State.

Importance Estimation

The future memory-lifecycle subsystem that estimates the context-sensitive significance of semantic knowledge and memory structures.

Offline Consolidation

Protected reorganization of Memory State outside the immediate online response path.

Sleep

A future operating mode for offline consolidation, pruning, structural analysis, and other expensive memory maintenance.

Replay

Controlled reactivation of selected semantic experience through the Transformer and the canonical Semantic Feedback Learning Pipeline.

Forgetting

Controlled reduction of accessibility, precision, or persistence for memory whose expected utility no longer justifies its cost or interference.

Memory Pruning

Removal or compression of redundant, obsolete, low-confidence, or harmful memory structures under explicit policy.

Structural Plasticity

Modification of Associative Memory topology based on accumulated evidence rather than ordinary online weight updates.

Global Evaluation

A future conservative subsystem integrating goals, context, memory, consequences, and candidate actions into system-level evaluation.

Multi-Agent Semantic Learning

Learning between Cognitive systems through exchanged Semantic Representations and local controlled UPDATE.

Input Buffer

A modality-neutral linear or circular field of fixed-dimensional input elements written sequentially before activation enters STM.

Input Buffer Element

One fixed-dimensional modality-neutral physical element of the Input Buffer, permanently connected to one corresponding STM node.

Transmission Context

The service coordinate reserved within an activation vector to preserve source or transmission mode without encoding Item identity.

Margin Note

A typed non-normative documentation object that preserves a deferred alternative or side observation outside the canonical architecture.

Trace List

A list of independently matchable local trace structures stored on one physical LTM connection and used as the associative-search domain at that connection.

Minimal Semantic Search Trace

A connection-local associative discriminator whose placement identifies a possible transition and whose value determines compatibility with the current activation.

Progressive Virtual Contraction

A semantic-search process in which the origin remains fixed while each successful transition replaces the temporary virtual endpoint, without intermediate switch-fabric reconfiguration.

Episode Graph Vertex

The unique storage location for the complete Transformer-produced vector of one element in one completed Logical Episode.

Sequencer

The Input / STM component that orders and normalizes the combined buffered stream, proposes Logical Episode boundaries, and delegates uncertain boundary cases to the main Transformer.

Long-Term Memory

The single physical persistent associative memory implemented by one shared vertex and connection array.

LTM-1

The semantic logical domain of the single physical LTM, accessed through MSG1 and its orthogonal message-specific state subspace.

LTM-2

The episodic MSG2-specific logical domain of the single physical LTM. LTM-2 has no independent propagation graph; MSG2 uses the persistent LTM-1 associative graph as its computational substrate.

MSG1

The element-LTM-1 message type operating exclusively in the MSG1 orthogonal state subspace.

MSG2

The completed-episode LTM message type carrying per-element contextual data and Transformer-defined causal topology in the MSG2 orthogonal state subspace.

Orthogonal Message-Specific State Subspace

The portion of LTM vertex and connection state activated and updated exclusively by one message type.

Associative Retrieval Wave

A repeated local match-and-transition process confined to one message-specific state subspace.

Sequence

A directed linear STM activation chain produced by the Sequencer; every node is assigned a position number that is carried by MSG2 during READ.

Memory Vector Readout

The fixed dimensionality-reduction stage that maps the distributed MSG2 response to Memory Vector cells using an experimentally selected operator.

Readout Entropy

The entropy of Memory Vectors over a representative distribution of LTM states and Event Queries; for deterministic READ it is the primary information-density metric for comparing readout operators.
