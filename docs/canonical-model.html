Canonical Terminology

Associative Match

The local confirmation that an LTM1 candidate is compatible with the object and its context; only confirmed matches may participate in an LTM2 update.

Associative Retrieval Wave

A repeated local match-and-transition process confined to one message-specific state subspace.

Context

One or two existing LTM1 links used to constrain and disambiguate the associative match of an object.

Contextual Four-Tuple

The working UPDATE unit consisting of object, context, previous, and next; previous and next are realized by the STM chain structure.

Contextual Retriever

The Associative Memory role that returns a serialized memory message through explicit READ without modifying Memory State.

Dialogue

A logically connected exchange of messages with the external world. Its first exchange is processed without memory READ; the first UPDATE creates dialogue context for later cycles.

Dialogue Context (D-Context)

The evolving state of one Dialogue, created by the first UPDATE and maintained only inside Associative Memory. READ uses the D-Context to select relevant memory information; later UPDATE operations extend it.

Dialogue Projection

The associations, episodes, scenarios, and other long-term structures made relevant by the current D-Context.

Episode Graph Vertex

The unique storage location for the complete Transformer-produced vector of one element in one completed Logical Episode.

First Dialogue Exchange

The opening external exchange of a Dialogue, processed by Transformer without memory READ and followed by the UPDATE that initializes D-Context.

Forgetting

Controlled reduction of accessibility, precision, or persistence for memory whose expected utility no longer justifies its cost or interference.

Global Evaluation

A future conservative subsystem integrating goals, context, memory, consequences, and candidate actions into system-level evaluation.

Importance Estimation

The future memory-lifecycle subsystem that estimates the context-sensitive significance of semantic knowledge and memory structures.

Input Buffer

A modality-neutral linear or circular field of fixed-dimensional input elements written sequentially before activation enters STM.

Input Buffer Element

One fixed-dimensional modality-neutral physical element of the Input Buffer, permanently connected to one corresponding STM node.

Internal Language

The Transformer-derived language used for communication among cognitive subsystems.

Long-Term Memory

The single physical persistent associative memory implemented by one shared vertex and connection array.

LTM1

The conservative associative graph containing the current set of stable Internal Language Atoms together with their Atom S-Contexts.

LTM2

The long-term store of compositions, episodes, scenarios, and Dialogue history expressed in the internal language.

Margin Note

A typed non-normative documentation object that preserves a deferred alternative or side observation outside the canonical architecture.

Memory Pruning

Removal or compression of redundant, obsolete, low-confidence, or harmful memory structures under explicit policy.

Memory Serialization

The expression, as an ordered message in the Internal Language, of the information subset selected by the current D-Context.

Memory State

The dynamic internal state of Associative Memory, including persistent and short-lived organization.

serialized memory message

A legacy low-level name for one vector element of a serialized internal-language memory message; it is not a separate language or aggregated memory state.

Minimal Semantic Search Trace

A connection-local associative discriminator whose placement identifies a possible transition and whose value determines compatibility with the current activation.

MSG1

The element-LTM1 message type operating exclusively in the MSG1 orthogonal state subspace.

MSG2

The STM-emitted LTM message MSG2(amplitude, sequence_number, operation). Its operation field initially supports READ and UPDATE. Every MSG2 excites LTM1 and propagates only through the persistent LTM1 graph; UPDATE participation in LTM2 is permitted only after a confirmed associative match.

MSG2 Operation

The per-message local instruction carried by MSG2. Initial values are READ and UPDATE; the operation is interpreted by the receiving LTM1 node.

Multi-Agent Semantic Learning

Learning between Cognitive systems through exchanged Semantic Representations and local controlled UPDATE.

Offline Consolidation

Protected reorganization of Memory State outside the immediate online response path.

Orthogonal Message-Specific State Subspace

The portion of LTM vertex and connection state activated and updated exclusively by one message type.

Progressive Virtual Contraction

A semantic-search process in which the origin remains fixed while each successful transition replaces the temporary virtual endpoint, without intermediate switch-fabric reconfiguration.

READ

The dialogue-aware operation that selects relevant prior dialogue context and its projection onto long-term memory, then serializes it in the internal language.

Replay

Controlled reactivation of selected semantic experience through the Transformer and the canonical Semantic Feedback Learning Pipeline.

Semantic Feedback Learning

Learning in which Transformer-produced semantic representations update Associative Memory.

Semantic Feedback Learning Pipeline

The first-class architectural process coordinating the closed self-learning loop.

Semantic Learner

The Associative Memory role that incorporates Transformer-produced Semantic Representations into Memory State through UPDATE.

Semantic Representation

The canonical semantic object accepted by UPDATE.

Semantic Teacher

The Transformer role that produces semantic representations suitable for Associative Memory learning.

Sequence

A directed linear STM activation chain. External input chains are produced by the Sequencer; UPDATE chains are constructed directly by Transformer with already defined starts, ends, order, and structural links.

Sequencer

The Input / STM component that orders and normalizes the combined buffered stream, proposes Logical Episode boundaries, and delegates uncertain boundary cases to the main Transformer.

Serialized Memory Message

The sequence returned by memory to Transformer containing prior Dialogue content and its relevant projection onto LTM1 and LTM2.

Sleep

A future operating mode for offline consolidation, pruning, structural analysis, and other expensive memory maintenance.

STM

The short-term transport and context substrate that orders internal-language messages and maintains the active Dialogue.

Structural Plasticity

Modification of Associative Memory topology based on accumulated evidence rather than ordinary online weight updates.

Trace List

A list of independently matchable local trace structures stored on one physical LTM connection and used as the associative-search domain at that connection.

Transformer

The trained reasoning subsystem that interprets external input, defines the internal language at a selected intermediate representation, and processes serialized memory messages.

Transmission Context

The service coordinate reserved within an activation vector to preserve source or transmission mode without encoding Item identity.

UPDATE

The operation that carries a new Transformer-produced internal state to memory and extends the current D-Context; it is locally interpreted by receiving LTM1 nodes.

Internal-Language Extraction Point

The selected Transformer depth at which external input has been converted into the internal language and memory-facing READ or UPDATE content can be formed.

Memory Reinjection Point

A deeper Transformer depth at which serialized memory, already expressed in the internal language, is integrated without repeating early external-form interpretation.

Atom S-Context

Semantic Context: the stable local semantic environment associated with an Internal Language Atom and required for its interpretation.
