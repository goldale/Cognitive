Chapter 12

Relevant Memory Selection and Serialization

Section 12.1

Selection and Serialization Contract

Associative Memory does not generate a separate semantic representation. In response to READ, it selects relevant information already represented in the internal language and serializes that information for Transformer processing.

Single-language contract

The semantic space used for READ input, UPDATE input, D-Context, and memory output is the same Transformer-derived internal language.

Serialized Memory Message

A bounded ordered sequence in the internal language containing prior Dialogue content and its relevant projection onto LTM1 and LTM2.

Serialized Memory Message = D-Context + Relevant Long-Term Projection

Low-level vector elements

A vector may remain as a low-level element of the internal-language sequence. It is not an aggregated memory state, a separate language, or an independently generated semantic object.
