Chapter 12

Learning and Memory Update

Section 12.6

Progressive Training Strategy

Transformer is trained first and already defines the internal language. Associative Memory then develops inside that language, beginning empty and learning a Transformer-specific model of experienced reality.

Stage 1 — Transformer baseline

The Transformer learns interpretation, reasoning, planning, and generation before Associative Memory contains experience. The selected intermediate interface is identified and validated as the shared internal language.

Stage 2 — Dialogue Context and LTM1 vocabulary

The first exchange of each new Dialogue is processed without READ. Its first UPDATE creates Dialogue Context. Repeated internal-language states then teach LTM1 stable atoms, contexts, and associative matches.

Stage 3 — LTM2 compositions and scenarios

After LTM1 has enough stable vocabulary, LTM2 accumulates compositions, episodes, state transitions, and scenarios. The stages overlap, but the dominant learning priority shifts from vocabulary to experienced structure.

Risk of ignored memory

A capable Transformer may solve many tasks from parameters and current input alone. Training must therefore measure whether serialized memory messages causally improve Dialogue continuity, recall, prediction, or decisions.

No separate memory-language training

The memory is not trained to invent or canonicalize a second language. It learns to organize, select, and serialize information in the Transformer-defined internal language.
