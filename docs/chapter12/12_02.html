Chapter 12

Relevant Memory Selection and Serialization

Section 12.2

Sources of Relevance

Relevance is determined from the active D-Context, the current internal-language quasi-query, LTM1 spreading activation, and linked LTM2 episodes, compositions, and scenarios.

SourceContribution
D-ContextPrior exchanges, active entities, current objectives, unresolved questions, and established references.
Current Transformer stateThe present internal-language quasi-query and active processing context.
LTM1Associative atoms, contexts, permanent links, activation paths, and match strength.
LTM2Relevant episodes, compositions, scenarios, and state transitions.

Dialogue-first relevance

For a continuing Dialogue, previous Dialogue content is the primary anchor. Long-term memory is projected relative to that anchor rather than retrieved independently of it.

First exchange exception

The first exchange of a new Dialogue has no memory READ. Its first UPDATE creates the initial D-Context required for meaningful later retrieval.
