# Cognitive 0.3.34 Release Notes

Release date: 2026-08-04

This release adds topology-oriented, physically heterogeneous Associative Memory architecture and documentation corrections.

## Architecture

- Adds specialized connection topologies for Input / Addressing, Pattern Separation, Associative Binding / Index, and Output / Projection.
- Defines function as emerging from node population, connectivity topology, activation dynamics, and update rules.
- States that each specialized topology is a candidate for its own dedicated hardware substrate.
- Uses hippocampal subsystem scale only as an initial relative hardware estimate, not a one-to-one neuron mapping.
- Treats Associative Memory as rapidly changing short-term and episodic memory; stable organization is produced through Offline Consolidation.
- Restores the canonical processing-depth hypothesis of 4–8 layers and removes obsolete 256-layer language.

## Documentation

- Scales diagrams in Sections 12.6 and 13.1 to 50% through a reproducible generator property.
- Replaces the Class III text in Section 14.1 with: “Partly defined and partly example-based, or fully defined but very complicated.”
- Preserves uniform table formatting without bold or italic emphasis.
