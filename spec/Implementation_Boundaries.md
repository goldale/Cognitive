# Implementation Boundaries

## Implemented

- Canonical Research State.
- Restricted YAML parsing and canonical serialization.
- Token and semantic validation.
- Change proposals.
- Structural three-way merge and conflict reports.
- Generated documentation.
- Objective-driven symbolic world model.
- Working and long-term memory.
- Functional forgetting and iterative architecture selection.
- Communication, clarification, integration, and conflict objects.
- Trainable multichannel evaluator.
- Trainable hybrid meta-architect.
- Cognitive lineage diversity manager.

## Research prototypes, not established solutions

- The particular flat, clustered, and hybrid memory candidates.
- The current evaluator feature channels.
- The meta-architect's initial priors.
- The numerical diversity metric.

## Not yet implemented as a mature solution

- Integrated holographic memory-model representation.
- Long-horizon persistent identity across model replacement and hardware migration.
- Self-hosted Research State language.
- Reliable emergence of social, emotional, ethical, or political behavior.
- General semantic consolidation without human-model review.
- Subjective consciousness.
